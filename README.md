# Вакансии с hh.ru — поиск, фильтрация и сохранение

## 📌 Описание

Данный проект позволяет получать вакансии с сайта [hh.ru](https://hh.ru), сортировать их по зарплате, фильтровать по ключевым словам в описании, сохранять и удалять данные в JSON-файле.

Интерфейс реализован через консоль, с возможностью расширения.

---

## 📁 Структура проекта
```
project/
│
├── src/
│ ├── vacancies.py # Классы HeadHunterAPI и Vacancy
│ ├── user_func.py # Фильтрация, сортировка
│ ├── file_manager.py # Абстрактный и конкретный классы для работы с файлами
│
├── data/
│ └── vacancies.json # JSON-файл для хранения вакансий
│
├── main.py # Основная точка входа в программу
├── README.md # Описание проекта (вы читаете его)
```

---

## 🚀 Возможности

- 🔍 Поиск вакансий по запросу с hh.ru
- 💰 Получение **топ-N** вакансий по зарплате
- 🧠 Фильтрация вакансий по ключевым словам в описании
- 💾 Сохранение и удаление вакансий в/из JSON-файла
- 📃 Консольный интерфейс с меню
